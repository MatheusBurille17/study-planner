# Amanda's Study Planner - Product Overview

## Product Summary

Amanda's Study Planner is a responsive, installable PWA (Progressive Web App) designed for university students to centralize and manage their academic life. The app consolidates tasks, exams, assignments, and seminars in one place, enabling efficient study planning and deadline tracking.

## Target User
- University students
- Single-user model with personal authentication
- Mobile-first, but fully functional on desktop and tablet

## Core Value Proposition
- **Centralization:** All academic activities in one place
- **Clarity:** Clear calendar views and dashboard overview
- **Automation:** Automatic deadline tracking and reminders
- **Accessibility:** Works offline, installable like native app

## Main Features

### Dashboard (Home Screen)
- Weekly/monthly summary of pending tasks
- Upcoming exams and assignment deadlines
- Quick statistics (completion %, study hours, etc.)
- "+ New Activity" entry point

### Tasks Management
- Create personal study activities (study content, review, exercises)
- Set priority (Low, Medium, High)
- Track status (To Do, In Progress, Completed)
- Optional: time estimates, custom tags, discipline assignment

### Calendar Integration
- Monthly and weekly views
- Color-coded activity types (tasks, exams, assignments)
- Visual urgency indicators
- Click-through to daily details

### Exams & Assignments
- **Exams:** Discipline, date/time, content, type, location
- **Assignments:** Discipline, deadline, description, type, criteria
- **Seminars:** Discipline, date/time, topic, location, presenters

## Notifications & Reminders
- Exam/assignment deadline: 24 hours before
- Task deadline: 2-3 hours before
- Customizable notification times
- Web push notifications + in-app alerts
- Works offline via Service Worker

## Design Principles
- **Minimalist:** Essential only, no clutter
- **Intuitive:** Clear navigation, logical flows
- **Modern:** Clean design with subtle accents
- **Responsive:** Mobile-first development

## Success Metrics
- Activity creation < 30 seconds
- 70%+ weekly retention rate
- Initial load < 3 seconds
- 100% offline functionality
- 60%+ notification engagement
