# Diretrizes de interface

As telas de referência estão em `docs/referencias-visuais/`.

- Consulte `docs/design/referencias-visuais/README.md` para o índice das telas e a linguagem visual observada.
- As imagens PNG são referências visuais; não devem ser usadas como imagens de fundo nem inseridas como substituto da interface.
- Quando a fidelidade visual for importante, peça/anexe no chat do Kiro a imagem individual da tela que está sendo implementada. A mera existência do arquivo no workspace não garante inspeção visual pelo modelo.
- Preserve o estilo mobile-first, o fundo off-white quente, os detalhes roxo/lilás, as cores pastel por categoria, os cartões arredondados e as sombras discretas.
- Mantenha os títulos serifados expressivos vistos nas referências e os textos funcionais simples e legíveis.
- Reproduza a navegação inferior das telas principais e a ação central de adicionar conforme as referências aplicáveis.
- Não invente requisitos funcionais com base apenas na aparência. Use os documentos de requisitos do projeto para regras e comportamentos.
- Antes de mudar padrões globais, verifique se já existem tokens, componentes e convenções no projeto; prefira reutilizá-los.
